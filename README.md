# 🚀 Overlord VPN Bot (Multi-Server Core V3)

Асинхронный Telegram-бот на базе **Aiogram 3.x** и **SQLAlchemy 2.0 (PostgreSQL)** для коммерческой автоматизации продаж VPN-подписок. Бот каскадно управляет распределенной сетью серверов через официальный API панелей **3x-ui** (ядро Xray).

## ✨ Ключевые фичи и Архитектура

*   **⚡ Высокая Отказоустойчивость (Fault Tolerance):** Работа с внешними нодами Xui изолирована в асинхронных циклах `try/except`. Сбой или оффлайн одной ноды партнера не прерывает транзакцию и не мешает зачислению доступов на остальные 4 рабочих сервера.
*   **💳 Двухканальный Биллинг (Ручной Пуллинг):** 
    *   **CryptoBot API:** Прием криптовалюты (USDT/TON) с автоматической конвертацией фиатных цен.
    *   **Lava.top V3 API:** Прием фиатных банковских карт (RUB/KZT) с использованием динамического параметра `amount` и единого `offerId`.
    *   *Никаких вебхуков:* Проверка статусов (`paid` / `COMPLETED`) выполняется по кнопке пользователя за долю секунды методом пуллинга.
*   **🛡 Атомарная защита FOR UPDATE:** Внедрены блокировки на уровне строк PostgreSQL. Исключены гонки условий (Race Condition) — сколько бы раз пользователь ни нажал кнопку «Проверить оплату», начисление произойдет ровно один раз.
*   **🔗 Монолитный UUID (Один Клиент — Одна Ссылка):** Генерация пакета `email` и `sub_id` вынесена до начала итерации серверов. У пользователя на всех нодах создаются абсолютно идентичные учетные записи, а в Личном кабинете выводится строго по одной чистой ссылке на каждую локацию.
*   **⏳ Умная очередь тарифов:** При покупке PREMIUM во время активного BASE, базовый тариф замораживается и уходит в отложенную очередь. Как только PREMIUM истекает, Cron-воркер автоматически активирует сохраненные дни BASE.
*   **📊 Профессиональная CRM-админка:** Пагинация списков пользователей (по 5 человек на экран), 1-click каскадный накат базы клиентов на новые сервера по API, и выгрузка ведомостей выплат 1-го числа.
*   **👥 Гибридная реферальная программа:** 
    *   *Обычные пользователи:* Получают бонусные дни 1:1 строго за первую покупку друга (защита от абуза).
    *   *PRO-партнеры (Блогеры / Менеджеры):* Получают 10% CPA пожизненно в USD с каждой оплаты реферала. Партнерский кабинет встроен в том числе и для администрации.

## ⚙️ Установка и запуск в 2 простых шага

### Шаг 1: Клонирование и настройка окружения
1. Зайдите на ваш сервер через SSH, склонируйте проект и перейдите в его папку:
   ```bash
   git clone https://github.com/iermiloff/multi-server-VPN-bot/ && cd multi-server-VPN-bot
   ```
2. Создайте файл `.env` из примера:
   ```bash
   cp .env.example .env
   ```
3. Откройте его через редактор (`nano .env`) и вставьте ваши рабочие токены бота, администраторов и доступы к базе данных PostgreSQL.
   
### Шаг 2: Запуск всей системы одной командой

Просто скопируйте и выполните эту команду в терминале вашего сервера. Docker Compose сам автоматически скачает чистую базу данных PostgreSQL, создаст пользователя и пароль из вашего `.env`, скомпилирует бота и запустит всю систему в связке:

```bash
git pull && docker compose up -d --build && docker compose logs -f multi-server-vpn-bot
```

*Система работает полностью на автопилоте: SQLAlchemy сама создаст все таблицы в новой базе данных при первом старте, добавит заглушку поддержки и включит фоновый планировщик.*

## 👑 Первичная настройка VPN-сети (Инструкция для админа)

После запуска контейнера вся дальнейшая настройка выполняется прямо внутри Telegram через удобные инлайн-кнопки.

### 1. Настройка канала техподдержки
1. Зайдите в ваш Telegram-бот и напишите команду `/admin`.
2. Перейдите в меню **«📢 Каналы-партнеры»**.
3. Вы увидите системную заглушку техподдержки. Нажмите кнопку **«Удалить»** возле нее.
4. Нажмите **«➕ Добавить канал»**:
   * Введите цифровой ID вашего официального канала (например, `-1001234567890`).
   * Введите название (например, `Техподдержка Overlord`).
   * Вставьте инвайт-ссылку на канал.
   * На шаге 4/4 выберите тип: **«🛠 Обязательный»**.
   *(Теперь бот активирован для всех пользователей, и они не смогут зайти в меню, пока не подпишутся на ваш саппорт).*

### 2. Подключение серверов 3x-ui
1. В меню `/admin` перейдите в **«🖥 Управление серверами»**.
2. Нажмите **«➕ Добавить сервер»**:
   * Введите имя (например, `Нидерланды #1`).
   * Введите URL API (например, `http://155.155.155.155:2053`).
   * Вставьте **Bearer API Token** (его нужно скопировать в самой панели 3x-ui в разделе *Настройки панели -> Безопасность -> API Token*).
   * Введите **Порт подписки** (из раздела *Настройки панели -> вкладка Подписка -> Порт подписки по умолчанию*, обычно это `2096`).

### 3. Привязка портов к тарифам
1. В меню управления серверами кликните по добавленному серверу. Бот мгновенно запросит по API список всех ваших инбаундов.
2. Просто кликайте по кнопкам портов, чтобы циклически менять их статус:
   * `⚫ НЕАКТИВЕН` — пользователи не получат этот порт.
   * `🟢 BASE` — порт добавится в базовую подписку.
   * `💎 PREMIUM` — порт добавится только VIP-клиентам.
