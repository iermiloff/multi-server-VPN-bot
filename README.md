# 🚀 Overlord Multi-Server-VPN Bot (3x-ui SaaS v3.5.0+)

Асинхронный Telegram-бот на **aiogram 3.x** для коммерческой продажи VPN-подписок с поддержкой мультисерверной архитектуры 3x-ui панелей через механизм **Subscription Server**.

## 🛠 Быстрый запуск (Инструкция)

### Шаг 1: Подготовка окружения
1. Склонируйте репозиторий
   ```bash
git clone https://github.com/iermiloff/multi-server-VPN-bot/
cd multi-server-VPN-bot
   ```  
2. Скопируйте файл настроек и заполните его вашими данными:
   ```bash
   cp .env.example .env
   nano .env
   ```

### Шаг 2: Локальный запуск (venv)
1. Разверните и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Накатите структуру базы данных PostgreSQL через Alembic:
   ```bash
   alembic upgrade head
   ```
4. Запустите бота:
   ```bash
   python3 main.py
   ```

### Шаг 3: Запуск через Docker
Если вы предпочитаете контейнеризацию, соберите и запустите проект одной командой:
```bash
docker build -t multi-vpn-bot .
docker run -d --name vpn-bot --env-file .env multi-vpn-bot
```

## 👑 Инструкция для Администратора (Первый запуск)
1. Напишите боту команду `/start`. Бот выдаст ошибку, так как в системе еще нет главного канала.
2. Перейдите в терминал СУБД или выполните команду `/admin` (ваш Telegram ID должен быть в `ADMIN_IDS`).
3. Зайдите в меню **"Каналы-партнеры" -> "Добавить канал"** и создайте канал с типом **"Саппорт"** (это разблокирует бота для всех).
4. Зайдите в меню **"Управление серверами" -> "Добавить сервер"**. Введите URL панели, Bearer-токен и порт подписки (по умолчанию `2096`).
5. Нажмите **"Настроить сервер"** и привяжите нужные входящие порты (инбаунды) к тарифу **BASE**. 

*Бот полностью готов к автоматическому приему оплат и выдаче мультисерверных подписок!*
