# 🚀 Полноценный SaaS-дистрибутив Overlord Multi-Server-VPN Bot

Готовое коммерческое решение для автоматической продажи VPN-подписок через мультисерверные панели 3x-ui (v3.5.0+). Бот автоматически нарезает подписки через **Subscription Server** панелей и выдает пользователю одну удобную ссылку.

## ✨ Что умеет бот (Возможности и функционал)

*   🌐 **Мультисерверность (SaaS-модель)**: Подключение неограниченного количества локаций (серверов 3x-ui) прямо через админку бота в Telegram. Никакого хардкода серверов в коде или конфигурационных файлах.
*   🔗 **Технология Subscription Server**: Бот больше не заваливает пользователя кашей из сырых ключей (`vless://`, `trojan://`). Он выдает **всего одну универсальную ссылку подписки** для каждого сервера. Приложения на устройствах клиентов (v2rayNG, FoXray и др.) автоматически скачивают и обновляют конфигурации через эту ссылку.
*   🎭 **Гибкое разделение на тарифы**: Администратор может разделять входящие порты (инбаунды) на серверах по двум тарифным планам: `BASE` (базовый доступ) и `PREMIUM` (VIP-порты с повышенной скоростью или Reality/gRPC маскировкой). Премиум-клиенты автоматически получают доступ к пулу портов обоих тарифов.
*   🎁 **Автоматизированный маркетинг («Месяц от партнеров»)**: Встроенный инструмент привлечения трафика. Бот выдает пользователям бесплатные 30 дней базового тарифа за подписку на каналы спонсоров. Список спонсоров гибко настраивается через админку.
*   🛡️ **Защита от хитрых отписок**: Встроенный фоновый планировщик (`APScheduler`) регулярно проверяет профили «бесплатных» клиентов. Если пользователь отписался от канала-партнера, бот мгновенно аннулирует его подписку в СУБД и каскадно удаляет его аккаунт со всех серверов 3x-ui.
*   🛠️ **Обязательный саппорт-канал**: Возможность заблокировать главное меню бота до тех пор, пока пользователь не подпишется на ваш официальный канал техподдержки.
*   🧾 **Автоматический прием оплат**: Полная интеграция с платежной системой **Crypto Pay (@CryptoBot)** для мгновенного приема криптовалюты и автоматической активации доступа без участия администратора.
*   📦 **Zero-Configuration развертывание**: Идеально подходит для продажи как готовое решение под ключ. При первом старте Docker-контейнера система сама создает таблицы в PostgreSQL, настраивает структуру Alembic и генерирует системные заглушки.

## 📁 Структура проекта (Проверьте перед запуском)

Убедитесь, что в вашем репозитории файлы разложены строго по следующим папкам. 

```text
├── database/                # Модули базы данных 
│   ├── db_helper.py
│   └── models.py
├── handlers/                # Обработчики команд 
│   ├── admin.py
│   └── user.py
├── services/                # API и логика
│   ├── cryptobot.py
│   ├── scheduler.py
│   └── xui.py
├── .env                     # Файл с настройками (создадите сами)
├── alembic.ini              # Конфиг миграций
├── Dockerfile               # Инструкция сборки контейнера
├── entrypoint.sh            # Скрипт автоматического запуска
└── main.py                  # Главный файл запуска бота
```

## ⚙️ Установка и запуск в 2 простых шага

### Шаг 1: Клонирование и настройка окружения
1. Зайдите на ваш сервер через SSH, склонируйте проект и перейдите в его папку:
   ```bash
   git clone https://github.com/iermiloff/multi-server-VPN-bot/ && cd multi-server-VPN-bot
   ```
2. Создайте файл `.env` из примера:
   ```bash
   cp .env.example .env
   ```
3. Откройте его через редактор (`nano .env`) и вставьте ваши рабочие токены бота, администраторов и доступы к базе данных PostgreSQL.
   
### Шаг 2: Запуск контейнера

Просто скопируйте и выполните эту команду в терминале вашего сервера (название `multi-server-vpn-bot` везде строго одинаковое):
```bash
docker build -t multi-server-vpn-bot . && docker run -d --name multi-server-vpn-bot --env-file .env multi-server-vpn-bot
```

*Система сама распознает, что папка миграций отсутствует, автоматически сгенерирует структуру Alembic на лету внутри контейнера, свяжет ее с файлом `database/models.py`, создаст нужные таблицы в вашей PostgreSQL, добавит системную заглушку техподдержки и запустит бота.*

## 👑 Первичная настройка VPN-сети (Инструкция для админа)

После запуска контейнера вся дальнейшая настройка выполняется прямо внутри Telegram через удобные инлайн-кнопки.

### 1. Настройка канала техподдержки
1. Зайдите в ваш Telegram-бот и напишите команду `/admin`.
2. Перейдите в меню **«📢 Каналы-партнеры»**.
3. Вы увидите системную заглушку техподдержки. Нажмите кнопку **«Удалить»** возле нее.
4. Нажмите **«➕ Добавить канал»**:
   * Введите цифровой ID вашего официального канала (например, `-1001234567890`).
   * Введите название (например, `Техподдержка Overlord`).
   * Вставьте инвайт-ссылку на канал.
   * На шаге 4/4 выберите тип: **«🛠 Обязательный»**.
   *(Теперь бот активирован для всех пользователей, и они не смогут зайти в меню, пока не подпишутся на ваш саппорт).*

### 2. Подключение серверов 3x-ui
1. В меню `/admin` перейдите в **«🖥 Управление серверами»**.
2. Нажмите **«➕ Добавить сервер»**:
   * Введите имя (например, `Нидерланды #1`).
   * Введите URL API (например, `http://155.155.155.155:2053`).
   * Вставьте **Bearer API Token** (его нужно скопировать в самой панели 3x-ui в разделе *Настройки панели -> Безопасность -> API Token*).
   * Введите **Порт подписки** (из раздела *Настройки панели -> вкладка Подписка -> Порт подписки по умолчанию*, обычно это `2096`).

### 3. Привязка портов к тарифам
1. В меню управления серверами кликните по добавленному серверу. Бот мгновенно запросит по API список всех ваших инбаундов.
2. Просто кликайте по кнопкам портов, чтобы циклически менять их статус:
   * `⚫ НЕАКТИВЕН` — пользователи не получат этот порт.
   * `🟢 BASE` — порт добавится в базовую подписку.
   * `💎 PREMIUM` — порт добавится только VIP-клиентам.
